# 2.5D Geometry 4.1 — Unity Modeling

Clean V4 geometry editor for Maker Studio.

## Main changes in 4.1

- Ctrl+Z / Ctrl+Y in Terrain Studio and Model Studio
- smooth, real-time camera orbit instead of fake preview translation
- Unity-style transform gizmos and camera navigation
- precise Multi-Cut at the clicked U/V coordinate
- Cross / U-line / V-line cut modes
- unlimited editable quad faces
- per-polygon material list
- visual UV island workspace
- interactive post-extrude stretching with the face Normal gizmo
- Inset, Bevel, Subdivide, loop-style U/V cuts, Duplicate, Flip, Delete and Weld

## Data compatibility

Uses the V4 clean files under:

`Data/VERMEIL_GEOMETRY_V4/`

It intentionally does **not** read the old `Data/VERMEIL2_5D/` JSON data.

Requires [VERMEIL] Visual 2.5D v6.0.0 or later.
