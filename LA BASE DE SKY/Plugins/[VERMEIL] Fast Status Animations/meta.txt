#=====================================================================
# About this plugin
#=====================================================================
#
# Fixes pause issues caused by status moves and stat changes.
# Status moves (Spore, Growth, etc.) now play a fast 4-frame flash
# instead of a full cinematic animation. Stat changes (StatUp,
# StatDown) and status inflictions (Sleep, Poison, etc.) skip
# their animations entirely, showing only the message.
#
# Damage moves are unaffected and continue to use the New Animation
# Editor system as before.
#
#=====================================================================
# What it does
#=====================================================================
#
# - Overrides Battle::Scene#pbAnimation to detect status moves
# - Overrides Battle::Scene#pbCommonAnimation for stat/status anims
# - Overrides Battler#pbInflictStatus to skip status animation
# - Overrides Battler#pbRaiseStatStage/pbLowerStatStage to skip anims
#
# Result: Status moves go from ~3s (3 blocking calls) to ~0.5s
#
#=====================================================================
