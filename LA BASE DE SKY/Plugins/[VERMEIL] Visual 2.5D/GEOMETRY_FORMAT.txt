VERMEIL 2.5D - Surface Geometry format v1
==========================================
Path per map: Data/VERMEIL2_5D/MapXXX.json
Example for Map012:

{
  "format": 1,
  "map_id": 12,
  "width": 40,
  "height": 30,
  "height_step": 32,
  "inherit_legacy": true,
  "cells": {
    "10,8": { "level": 2, "material": "default" },
    "11,8": { "height": 64, "material": "default" }
  },
  "ramps": []
}

With `inherit_legacy: true` (default), absent cells keep the height inferred from
legacy Terrain Tags. A stored `{ "level": 0 }` explicitly flattens a cell. This
allows gradual migration of existing maps. Set `inherit_legacy: false` only when
the JSON should be the complete authority for the map. `level` is multiplied by
height_step; explicit `height` pixels take precedence. `material` is reserved for
the Cliff Materials milestone.

The Maker Studio VERMEIL Geometry mod writes this format directly.
