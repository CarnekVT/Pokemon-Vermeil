VERMEIL Visual 2.5D v4.0.0
===========================
- Terrain Tags visuales reconstruidos desde cero.
- IDs 19-26 reutilizados como nucleo NDS; 27-33 para casos especializados.
- Eliminados del renderer los usos visuales de Mode7Tag, Mountains, Ladders,
  LaddersSide y HoneyTree.
- Eliminado 014_SideLadders.rb y su JSON.
- Eliminado camera-lift por Terrain Tag.
- Passability 2.5D ahora solo bloquea walls NDS explicitos.
- Priority ya no decide altura de roofs: NDSRoof/NDSRoofHigh tienen altura fija.
- NDSStructure añadido para casas/edificios 2D indivisibles.
- NDSMountainTop/NDSMountainWall añadidos para montanas/acantilados.
- NDSOverlay añadido para copas, aleros y foreground.
- Personajes/eventos siguen la altura de NDSVolume/NDSVolumeHigh/MountainTop.
- Subpixel preservado en posicion de personajes.
- Indoor renombrado y separado: NDSIndoorWall/Prop/Border/Black.
